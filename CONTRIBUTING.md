# Contribuir a Job-radar

¡Gracias por tu interés! Las contribuciones son bienvenidas.

## Cómo empezar
1. Haz un *fork* y clona el repositorio.
2. Sigue el README para levantar el entorno (sección "Puesta en marcha rápida").
3. Crea una rama descriptiva: `git checkout -b feat/mi-cambio` o `fix/mi-cambio`.

## Antes de abrir un Pull Request
- Asegúrate de que **la CI pasa en verde** (build + checks).
- Mantén los cambios acotados y con mensajes de commit claros.
- Si cambias comportamiento, explica el porqué en la descripción del PR.
- **No incluyas secretos ni datos personales** (revisa `.gitignore`).

## Estilo
**TypeScript / Astro** (web), **Node** (worker) y **Python** (scraper) — sigue las convenciones del código ya existente.

## Reportar bugs o proponer mejoras
Usa las **plantillas de Issues**. Cuanto más contexto (pasos, entorno, logs), mejor.

Al contribuir, aceptas que tu aportación se publique bajo la licencia [MIT](LICENSE).
