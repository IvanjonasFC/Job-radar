# Política de seguridad

## Versiones soportadas
Se da soporte a la última versión de la rama `main`.

## Reportar una vulnerabilidad
Por favor, **no abras un issue público** para vulnerabilidades de seguridad.
Usa la pestaña **Security → Report a vulnerability** (GitHub Security Advisories) de este
repositorio para un reporte privado. Intentaré responder en un plazo razonable.

Gracias por la divulgación responsable.
